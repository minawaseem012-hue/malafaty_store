ملفاتي

سياسة الخصوصية — مسودة

هذه صفحة أولية تحتاج مراجعة وتحديثًا قبل إطلاق المتجر فعليًا. المتجر الحالي تجريبي ولا يجمع مدفوعات حقيقية.

المعلومات

قبل الإطلاق، يجب تحديد البيانات التي سيجمعها الموقع، مثل البريد الإلكتروني وسجلات الطلبات، وسبب جمعها ومدة الاحتفاظ بها.

الدفع

عند ربط مزود دفع، تُعالج بيانات الدفع وفق سياسة مزود الخدمة. لا ينبغي تخزين بيانات البطاقات أو كلمات المرور أو مفاتيح API السرية داخل ملفات الموقع العامة.

التواصل

استبدل بيانات التواصل التجريبية بوسيلة دعم تملكها وتستطيع متابعتها قبل نشر الموقع.

تنبيه: هذه المسودة ليست استشارة قانونية، ويجب تكييفها مع طريقة عمل المتجر والقوانين المنطبقة.
